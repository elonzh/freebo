# Quality bar

The user pinned Chrome-like desktop layout, custom title bar and code-first construction. Browser tabs, navigation, address field and native window controls must align as a single desktop shell. App-only pages are compact utility panels. Emby remains the browsing/sign-in interface. IINA remains the user's player.

Verify Chinese and English labels, dark/light appearance, minimum 820×600 window, visible keyboard focus, draggable background with clickable tabs, usable settings panels, server form, error recovery above the WebContentsView, and persistent language changes. Tabs close without deleting registered servers. Music and live TV keep using the server page.

No image comp is approved. Fresh actual-app screenshots calibrate the finish; old captures do not certify the redesign. The website retains its own incumbent design and only needs branding, routes and current app screenshots updated. Real runtime validation is separate from packaging and simulated tests.
