# 浏览器加载、标签 hover 与账号密码验证

2026-10-06，macOS / Electron 44.5.1，使用真实 Electron 引擎验证。认证测试使用独立用户数据目录和本地 Emby API / 登录表单夹具；实际部署只检查公开信息接口和自动填写，没有提交真实服务器登录，也没有输出真实账号密码。

## 已验证

- 网页存在延迟资源时，标签图标持续转圈，刷新按钮显示停止；点击停止后图标与刷新按钮恢复。DOM 就绪时表单可见，但加载提示继续保留到资源加载结束。
- 使用连接 Electron 引擎的 DevTools 强制 hover 状态：非激活标签显示整体圆角背景；激活标签的标题按钮没有单独背景或文字颜色变化。
- 服务器编辑表单直接显示账号和密码，没有开关。填写后保存，延迟出现的登录表单自动填写账号与密码，没有自动提交。
- 实际 Emby 4.9.5.0 登录页使用 `#!/startup/manuallogin.html?serverId=…`，字段 ID 动态生成为 `embyinput0` / `embyinput1`。修复路由匹配后，原有账号及掩码密码在真实登录页自动出现，仍停留在登录页。
- 测试连接通过自有页面 IPC 和 Electron Session 调用本地公开信息、认证和注销接口。错误密码显示明确失败原因，正确密码显示服务器名和认证成功，没有触发服务器保存。
- 真实 `emby.naikonav.com` 部署的公开信息测试返回服务器名称与 `authenticated: false`。该部署对公开信息请求中未登录的授权头返回 403，测试现已对公开信息使用匿名请求，认证请求才添加授权头。
- 重启 Electron 后重新编辑服务器，账号及掩码密码仍然保留。
- 清除账号密码并保存后，本地凭据文件的条目已移除，再次打开登录页时字段保持空白。
- 更新后的深色表单在标准窗口和 820×600 原生窗口中已目视检查；最小窗口可滚动到账号、密码、测试连接和保存按钮。标准窗口中账号密码并排，完整表单及连接反馈可见。
- macOS 实际系统加密写入后的 `settings.json` 和 `credentials.json` 不含测试账号或密码明文，凭据文件权限为 `0600`。
- 65 项 Vitest 测试覆盖加密持久化、并发保存与移除、系统加密不可用、损坏数据、来源和子路径隔离、真实登录路由和动态 ID、延迟表单、用户输入保护、密码创建字段、临时读取失败恢复，以及表单的保留、清除和测试连接。API 测试覆盖反向代理子路径、旧 API 回退、错误认证、非 Emby 响应、超时、凭据放入请求体、禁止重定向和测试令牌注销。完整质量检查使用 `prek run --all-files`。

## 验证边界

登录夹具运行在真实 Electron WebContentsView 与沙箱预加载中；实际部署的自动填写也已验证。没有提交真实服务器账号认证，没有验证其他定制登录页或 Emby Connect；Windows / Linux 的系统加密和原生窗口仍需对应平台验收。测试令牌注销使用单独的 5 秒超时，服务器此时不可达时只能确认认证结果，不能保证令牌已注销。
