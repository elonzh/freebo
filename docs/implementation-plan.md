# 首版实施与验收

## 已确认范围

macOS、Windows、Linux；Apache-2.0；pnpm、React、Electron、Vite、Vitest；应用内 Emby 网页；自动发现外部播放器；安装指引；图形化设置。电影、剧集、视频播放列表，支持连播、续播、进度回传、字幕音轨及视频版本。音乐、直播沿用网页行为。IINA 优先完成实际验证。

产品名 Freebo，中文福瑞播。媒体服务器使用可扩展的 Provider 接口，目前只实现 Emby；中文、英文及跟随系统语言；Chrome 风格桌面标签栏、自定义标题栏和导航工具栏。代码与项目页保留本地，不提交或推送。

## 实现层次

- 独立的服务器持久化会话和安全网页视图。
- Emby 网页适配器，接管用户的播放意图，保留播放顺序与选项。
- Emby API 适配器，解析媒体、字幕和进度事件。
- 播放器发现与适配器，统一启动、队列、状态和控制能力。
- 播放会话管理器，去重、生命周期、连播切换、回传与错误恢复。
- React 设置和首次使用界面。

当前接口与目录边界见 [架构说明](architecture.md)，实际完成程度见 [验证记录](validation.md)。
